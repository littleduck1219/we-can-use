Official courses for learning AI development, guides and blogs worth reading, and communities to join (including Korean resources).

## Official Courses

- **[Anthropic Academy](https://anthropic.skilljar.com/)** — Free self-paced courses from using Claude to API development and MCP (certificates).
- **[Anthropic Courses](https://github.com/anthropics/courses)** — Official GitHub courses: Claude API basics, prompt engineering, evals, tool use.
- **[Prompt Engineering Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial)** — Anthropic's hands-on tutorial in 9 chapters.
- **[OpenAI Academy](https://academy.openai.com/)** — Free courses and events from AI basics to prompting.
- **[DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/)** — 120+ free 1–2 hour courses on LLMs, agents, and RAG.
- **[Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners)** (110k★) — Microsoft's 21-lesson generative AI course.
- **[Hugging Face Learn](https://huggingface.co/learn)** — Free open-source courses on LLMs, agents, RL, and diffusion models.
- **[Google AI for Developers](https://ai.google.dev/)** — Gemini API docs and AI learning resources for developers.
- **[LLM Course](https://github.com/mlabonne/llm-course)** — Popular course with roadmaps and Colab notebooks, from fundamentals to engineering.

## Guides & Blogs

- **[Anthropic Prompt Engineering Guide](https://platform.claude.com/docs/en/docs/build-with-claude/prompt-engineering/overview)** — Comprehensive official guide to prompting techniques.
- **[Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents)** — Anthropic's landmark post on simple, composable agent patterns.
- **[Claude Code Best Practices](https://code.claude.com/docs/en/best-practices)** — Context management, planning, parallel sessions, and more.
- **[Simon Willison's Weblog](https://simonwillison.net/)** — Influential blog covering LLM and AI tooling news almost daily.
- **[Lil'Log](https://lilianweng.github.io/)** — Lilian Weng's in-depth analyses of agents and LLM internals.

## Communities

- **[r/ClaudeAI](https://www.reddit.com/r/ClaudeAI/)** — Active Reddit community for Claude and Claude Code tips.
- **[r/LocalLLaMA](https://www.reddit.com/r/LocalLLaMA/)** — Large Reddit community on local LLMs and open-source models.
- **[Claude Developers Discord](https://www.anthropic.com/discord)** — Official Claude developer Discord run by Anthropic.
- **[OpenAI Developer Community](https://community.openai.com/)** — Official forum for OpenAI API developers.
- **[Hacker News](https://news.ycombinator.com/)** — Where AI development news and discussions move fastest.
