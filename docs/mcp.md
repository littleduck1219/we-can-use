# MCP (Model Context Protocol)

MCP 서버, 디렉토리·레지스트리, 큐레이션 리스트 모음.

## 공식 (Official)

| 링크 | 설명 |
|------|------|
| [Model Context Protocol](https://modelcontextprotocol.io) | MCP 공식 문서 사이트로, 프로토콜 사양·아키텍처·시작 가이드를 제공 |
| [MCP Reference Servers](https://github.com/modelcontextprotocol/servers) | Filesystem, Fetch, Memory 등 공식 레퍼런스 MCP 서버 모음 저장소 |
| [Official MCP Registry](https://registry.modelcontextprotocol.io) | Anthropic·GitHub·Microsoft 등이 함께 운영하는 공식 MCP 서버 레지스트리 (REST API 제공) |
| [MCP Registry (GitHub)](https://github.com/modelcontextprotocol/registry) | 공식 MCP 레지스트리의 오픈소스 커뮤니티 저장소 |
| [MCP TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) | MCP 서버·클라이언트 개발용 공식 TypeScript SDK |
| [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk) | MCP 서버·클라이언트 개발용 공식 Python SDK |

| [mcp.so](https://mcp.so) | 2만 개 이상의 MCP 서버를 모아둔 커뮤니티 기반 MCP 마켓플레이스 |
