# Skills & Plugins

**English** | [한국어](skills-plugins.ko.md)

Skills, plugins, subagents, hooks, and the marketplaces that distribute them. Skills (SKILL.md) follow the open [Agent Skills](https://agentskills.io) standard, so they work in Claude Code, Codex, Gemini CLI, and any other supporting tool. Claude Code-specific items (hooks, status lines) are noted as such.
