# Claude Code 생태계

Claude Code의 스킬, 플러그인, 서브에이전트, 훅과 관련 마켓플레이스 모음.

## 공식 (Official)

| 링크 | 설명 |
|------|------|
| [anthropics/claude-code](https://github.com/anthropics/claude-code) | Claude Code 공식 저장소, 이슈 트래킹과 공식 plugin-dev 플러그인 포함 |
| [anthropics/skills](https://github.com/anthropics/skills) | Anthropic 공식 Agent Skills 저장소 (문서 편집, 아트, MCP 서버 생성 등 예제 스킬 모음) |
| [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community) | Anthropic이 운영하는 공개 커뮤니티 플러그인 마켓플레이스 카탈로그 |
| [Claude Code Docs - Skills](https://code.claude.com/docs/en/skills) | 스킬 작성·관리·공유에 대한 공식 문서 |
| [Claude Code Docs - Plugins](https://code.claude.com/docs/en/plugins) | 플러그인 제작과 마켓플레이스 배포 공식 가이드 |
| [Claude Code Docs - Subagents](https://code.claude.com/docs/en/sub-agents) | 커스텀 서브에이전트 정의와 컨텍스트 관리 공식 문서 |
| [Claude Code Docs - Hooks](https://code.claude.com/docs/en/hooks) | 훅 이벤트, 설정, JSON 입출력 형식 공식 레퍼런스 |
| [Claude Code Docs - MCP](https://code.claude.com/docs/en/mcp) | MCP 서버로 외부 도구를 연결하는 공식 레퍼런스 |
| [Agent Skills](https://agentskills.io) | Claude Code 스킬이 따르는 오픈 표준 Agent Skills 명세 사이트 |
