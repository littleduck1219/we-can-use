# Curation & Directory Sites

**English** | [한국어](directories.ko.md)

Tool-agnostic awesome lists, AI tool discovery sites, prompt resources, and benchmarks useful for choosing models.

**Sections:** [Awesome Lists](#awesome-lists) · [Directories & Discovery](#directories--discovery) · [Prompts & Resources](#prompts--resources) · [Benchmarks & Leaderboards](#benchmarks--leaderboards) · [Cross-Tool Registries](#cross-tool-skill--agent-registries)

## Awesome Lists

- **[awesome-ai-agents](https://github.com/e2b-dev/awesome-ai-agents)** (29k★) — The definitive curated list of autonomous AI agents and frameworks.
- **[awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)** — 100+ open-source LLM app examples: RAG, agents, agent skills.
- **[awesome-generative-ai](https://github.com/steven2358/awesome-generative-ai)** — Generative AI projects by domain: text, coding, image, video, audio.
- **[awesome-ai-tools](https://github.com/mahseema/awesome-ai-tools)** — AI tools by category: code generation, productivity, learning.
- **[Awesome-LLM](https://github.com/Hannibal046/Awesome-LLM)** — LLM papers, open models, training/inference frameworks, benchmarks.

## Directories & Discovery

- **[There's An AI For That](https://theresanaiforthat.com/)** — The largest AI tool directory, searchable by task.
- **[Futurepedia](https://www.futurepedia.io/)** — 4,000+ AI tools with categories and ratings.
- **[Future Tools](https://www.futuretools.io/)** — Community-vote-driven directory and news hub by Matt Wolfe.
- **[Toolify](https://www.toolify.ai/)** — 30,000+ AI tools ranked by traffic and popularity.
- **[AI Agents Directory](https://aiagentsdirectory.com/)** — Compare AI agents and agent skills by domain: coding, sales, voice.
- **[Hugging Face Spaces](https://huggingface.co/spaces)** — Run and explore open-source AI demo apps directly.

## Prompts & Resources

- **[Claude Code Prompt Library](https://code.claude.com/docs/en/prompt-library)** — Anthropic's copy-paste prompts, tagged by task and role.
- **[Anthropic Claude Cookbooks](https://github.com/anthropics/claude-cookbooks)** — Official notebook recipes: RAG, tool use, subagents.
- **[OpenAI Cookbook](https://developers.openai.com/cookbook)** — Official OpenAI API examples and guides.
- **[prompts.chat](https://prompts.chat/)** (167k★) — Community prompt-sharing platform (awesome-chatgpt-prompts).
- **[Prompt Engineering Guide](https://www.promptingguide.ai/)** — Techniques, papers, and examples, maintained by DAIR.AI.
- **[TLDR AI](https://tldr.tech/ai)** — Daily newsletter summarizing model releases, research, and dev tools in 5 minutes.
- **[Latent Space](https://www.latent.space/)** — AI engineering newsletter and podcast with a daily news roundup.

## Benchmarks & Leaderboards

- **[LMArena](https://arena.ai/)** — The definitive LLM ranking via Elo from blind votes by real users.
- **[Artificial Analysis](https://artificialanalysis.ai/)** — Independent comparison of intelligence, speed, and price per model.
- **[SWE-bench](https://www.swebench.com/)** — Evaluates coding agents on real GitHub issue resolution.
- **[Aider LLM Leaderboards](https://aider.chat/docs/leaderboards/)** — Real-world coding performance and cost on a polyglot editing benchmark.
- **[LiveBench](https://livebench.ai/)** — Regularly refreshes questions to prevent data contamination.
- **[Terminal-Bench](https://www.tbench.ai/)** — Evaluates agents' ability to complete tasks in terminal environments.
- **[OpenRouter Rankings](https://openrouter.ai/rankings)** — Model usage share rankings from real OpenRouter traffic.

## Cross-Tool Skill & Agent Registries

- **[LobeHub Skills](https://lobehub.com/skills)** — Cross-platform agent skill marketplace spanning Claude, Codex, ChatGPT.
- **[AgentSkillsHub](https://agentskillshub.dev/)** — 1,200+ security-scanned agent skills, with a Codex skills guide.
- **[Codex Marketplace](https://codex-marketplace.com/)** — Unofficial community registry of Codex plugins and skills (150+).
- **[Open WebUI Community](https://openwebui.com/)** — Tools, functions, prompts, and model presets for Open WebUI.
