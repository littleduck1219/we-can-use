## 공식 강좌

- **[Anthropic Academy](https://anthropic.skilljar.com/)** — Claude 활용부터 API 개발, MCP까지 다루는 무료 자기주도 강좌 (수료증 발급).
- **[Anthropic Courses](https://github.com/anthropics/courses)** — Claude API 기초, 프롬프트 엔지니어링, 평가, 도구 사용을 다루는 공식 강좌 저장소.
- **[Prompt Engineering Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial)** — 9개 챕터로 구성된 Anthropic 공식 실습 튜토리얼.
- **[OpenAI Academy](https://academy.openai.com/)** — AI 기초부터 프롬프트 활용까지 무료 강좌·이벤트 제공.
- **[DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/)** — LLM·에이전트·RAG 등을 1~2시간에 배우는 무료 단기 강좌 120+개.
- **[Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners)** (110k★) — 생성형 AI 앱 개발을 21개 레슨으로 가르치는 Microsoft 공식 강좌.
- **[Hugging Face Learn](https://huggingface.co/learn)** — LLM, 에이전트, 강화학습, 디퓨전 모델 무료 오픈소스 강좌.
- **[Google AI for Developers](https://ai.google.dev/)** — Gemini API 문서와 개발자용 AI 학습 리소스.
- **[LLM Course](https://github.com/mlabonne/llm-course)** — 로드맵과 Colab 노트북으로 기초부터 엔지니어링까지 배우는 인기 강좌.

## 가이드 & 블로그

- **[Anthropic 프롬프트 엔지니어링 가이드](https://platform.claude.com/docs/en/docs/build-with-claude/prompt-engineering/overview)** — Claude 공식 문서의 프롬프트 기법 종합 가이드.
- **[Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents)** — 단순하고 조합 가능한 패턴으로 에이전트를 설계하는 Anthropic의 대표 글.
- **[Claude Code Best Practices](https://code.claude.com/docs/en/best-practices)** — 컨텍스트 관리, 계획 수립, 병렬 세션 등 공식 모범 사례.
- **[Simon Willison's Weblog](https://simonwillison.net/)** — LLM·AI 도구 소식을 거의 매일 다루는 영향력 있는 개발자 블로그.
- **[Lil'Log](https://lilianweng.github.io/)** — 에이전트와 LLM 내부 원리를 깊이 분석하는 Lilian Weng의 기술 블로그.

## 커뮤니티

- **[r/ClaudeAI](https://www.reddit.com/r/ClaudeAI/)** — Claude·Claude Code 활용법을 공유하는 활발한 레딧 커뮤니티.
- **[r/LocalLLaMA](https://www.reddit.com/r/LocalLLaMA/)** — 로컬 LLM과 오픈소스 모델을 다루는 대형 레딧 커뮤니티.
- **[Claude Developers Discord](https://www.anthropic.com/discord)** — Anthropic이 운영하는 공식 개발자 디스코드.
- **[OpenAI Developer Community](https://community.openai.com/)** — OpenAI API 개발자 공식 포럼.
- **[Hacker News](https://news.ycombinator.com/)** — AI 개발 소식과 토론이 가장 빠르게 오가는 기술 뉴스 커뮤니티.

- **[모두의연구소](https://modulabs.co.kr/)** — 연구 랩(LAB)과 부트캠프를 운영하는 커뮤니티 기반 AI 교육 플랫폼.
- **[가짜연구소 (Pseudo Lab)](https://pseudo-lab.com/)** — 오픈 스터디·오픈소스 프로젝트를 운영하는 비영리 AI 연구 커뮤니티 (6,000명+).
