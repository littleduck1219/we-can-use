## Awesome 리스트

- **[awesome-ai-agents](https://github.com/e2b-dev/awesome-ai-agents)** (29k★) — SOTA AI 자율 에이전트·프레임워크를 총망라한 대표 큐레이션.
- **[awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)** — RAG, 에이전트, 에이전트 스킬 등 100+ 오픈소스 LLM 앱 예제.
- **[awesome-generative-ai](https://github.com/steven2358/awesome-generative-ai)** — 텍스트·코딩·이미지·비디오·오디오 분야별 생성형 AI 큐레이션.
- **[awesome-ai-tools](https://github.com/mahseema/awesome-ai-tools)** — 코드 생성, 생산성, 학습 리소스 등 카테고리별 AI 도구 리스트.
- **[Awesome-LLM](https://github.com/Hannibal046/Awesome-LLM)** — LLM 논문·오픈 모델·학습/추론 프레임워크·벤치마크 종합 리스트.

## 디렉토리 & 탐색

- **[There's An AI For That](https://theresanaiforthat.com/)** — 태스크 기반으로 검색하는 최대 규모 AI 도구 디렉토리.
- **[Futurepedia](https://www.futurepedia.io/)** — 4,000+ AI 도구를 카테고리·평점과 함께 제공.
- **[Future Tools](https://www.futuretools.io/)** — Matt Wolfe가 운영하는 커뮤니티 투표 기반 디렉토리·뉴스 허브.
- **[Toolify](https://www.toolify.ai/)** — 30,000+ AI 도구를 트래픽·인기 순으로 정리한 대형 디렉토리.
- **[AI Agents Directory](https://aiagentsdirectory.com/)** — 코딩·세일즈·보이스 등 분야별 AI 에이전트·스킬 비교 탐색.
- **[Hugging Face Spaces](https://huggingface.co/spaces)** — 오픈소스 AI 데모 앱을 직접 실행하며 탐색하는 커뮤니티 디렉토리.

## 프롬프트 & 리소스

- **[Claude Code Prompt Library](https://code.claude.com/docs/en/prompt-library)** — 작업·역할별로 태그된 Anthropic 공식 복붙 프롬프트 라이브러리.
- **[Anthropic Claude Cookbooks](https://github.com/anthropics/claude-cookbooks)** — RAG, 툴 사용, 서브에이전트 등 공식 노트북 레시피.
- **[OpenAI Cookbook](https://developers.openai.com/cookbook)** — OpenAI API 활용 예제·가이드 공식 쿡북.
- **[prompts.chat](https://prompts.chat/)** (167k★) — awesome-chatgpt-prompts 기반 커뮤니티 프롬프트 공유 플랫폼.
- **[Prompt Engineering Guide](https://www.promptingguide.ai/)** — DAIR.AI가 운영하는 프롬프트 기법·논문·예제 종합 가이드.
- **[TLDR AI](https://tldr.tech/ai)** — 모델 릴리스·연구·개발 도구를 5분 분량으로 정리하는 일간 뉴스레터.
- **[Latent Space](https://www.latent.space/)** — AI 엔지니어링 특화 뉴스레터 겸 팟캐스트. 일간 뉴스 라운드업 포함.

## 벤치마크 & 리더보드

- **[LMArena](https://arena.ai/)** — 실사용자 블라인드 투표 기반 Elo 방식의 대표 LLM 랭킹.
- **[Artificial Analysis](https://artificialanalysis.ai/)** — 모델별 지능 지수·속도·가격을 함께 비교하는 독립 분석 플랫폼.
- **[SWE-bench](https://www.swebench.com/)** — 실제 GitHub 이슈 해결 능력으로 코딩 에이전트를 평가.
- **[Aider LLM Leaderboards](https://aider.chat/docs/leaderboards/)** — 다국어 코드 편집 벤치마크로 실전 코딩 성능·비용 비교.
- **[LiveBench](https://livebench.ai/)** — 데이터 오염 방지를 위해 문제를 주기적으로 갱신하는 벤치마크.
- **[Terminal-Bench](https://www.tbench.ai/)** — 터미널 환경에서 에이전트 작업 수행 능력을 평가.
- **[OpenRouter Rankings](https://openrouter.ai/rankings)** — OpenRouter 실사용 트래픽 기반 모델 사용량·점유율 랭킹.
