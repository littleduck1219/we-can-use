# 앱 빌더 & 로컬 LLM

[English](app-builders-local-llm.md) | **한국어**

프롬프트로 앱을 만들어주는 vibe coding 플랫폼과 내 컴퓨터에서 오픈 모델을 실행하는 도구 모음.

**섹션:** [웹 앱 빌더](#웹-앱-빌더-vibe-coding) · [디자인 투 코드](#디자인-투-코드) · [로컬 LLM 런타임](#로컬-llm-런타임) · [모델 허브 & 오픈 웨이트 모델](#모델-허브--오픈-웨이트-모델)

## 웹 앱 빌더 (Vibe Coding)

- **[v0 (Vercel)](https://v0.app)** — 프롬프트로 풀스택 웹 앱을 생성하고 즉시 배포.
- **[Lovable](https://lovable.dev)** — AI와 대화하며 앱·웹사이트를 만드는 인기 플랫폼. 원클릭 배포.
- **[Bolt.new](https://bolt.new)** — 브라우저 안에서 대화형 AI로 웹사이트·앱·프로토타입 제작 (StackBlitz).
- **[Replit](https://replit.com)** — Replit Agent가 설명만으로 앱을 만들고 호스팅하는 클라우드 개발 플랫폼.
- **[Firebase Studio](https://firebase.studio)** — Gemini 기반으로 프런트·백엔드·모바일을 한곳에서 만드는 Google의 풀스택 AI 워크스페이스.
- **[Base44](https://base44.com)** — 자연어로 DB·인증·호스팅 내장 풀스택 앱 생성 (Wix 인수).
- **[Emergent](https://emergent.sh)** — 아이디어 설명만으로 코딩·디자인·배포를 처리하는 AI 에이전트 플랫폼.
- **[Create](https://www.create.xyz)** — 자연어를 앱·사이트·도구로 바꾸는 AI 빌더. AI 기능·외부 서비스 연동 내장.

## 디자인 투 코드

- **[Figma Make](https://www.figma.com/make/)** — 프롬프트로 코드 기반 프로토타입을 만들고 다듬고 배포하는 Figma의 AI 도구.
- **[Google Stitch](https://stitch.withgoogle.com)** — AI로 UI 디자인을 생성하고 코드로 내보내는 Google 디자인 도구.

## 로컬 LLM 런타임

- **[Ollama](https://ollama.com)** — 명령 한 줄로 오픈 모델을 로컬(과 클라우드)에서 실행하는 가장 인기 있는 LLM 러너.
- **[LM Studio](https://lmstudio.ai)** — GUI로 오픈 모델을 내려받아 실행하는 데스크톱 앱. 에이전트 기능 포함.
- **[llama.cpp](https://github.com/ggml-org/llama.cpp)** — 로컬 추론 생태계의 사실상 표준인 C/C++ 추론 엔진 (GGUF).
- **[vLLM](https://github.com/vllm-project/vllm)** — 고처리량·저지연 서빙 엔진. 프로덕션 셀프호스팅 추론의 표준.
- **[Jan](https://jan.ai)** — 로컬·온라인 모델을 모두 지원하는 오픈소스 ChatGPT 대안 데스크톱 앱.
- **[Open WebUI](https://github.com/open-webui/open-webui)** — Ollama·OpenAI 호환 API에 연결하는 셀프호스팅 웹 채팅 UI.
- **[LocalAI](https://localai.io)** — OpenAI API 호환 로컬 런타임. GPU 없이도 텍스트·오디오·비전 모델 실행.
- **[AnythingLLM](https://anythingllm.com)** — 문서 기반 RAG와 에이전트를 내 컴퓨터에서 돌리는 올인원 프라이빗 AI 앱.
- **[GPT4All](https://www.nomic.ai/gpt4all)** — 데이터를 어디에도 보내지 않는 Nomic의 프라이버시 중심 데스크톱 앱.
- **[Text Generation WebUI](https://github.com/oobabooga/text-generation-webui)** — 다양한 백엔드를 지원하는 오픈소스 로컬 LLM UI (oobabooga).
- **[Msty](https://msty.ai/)** — 로컬·원격 모델을 하나의 인터페이스에서 다루는 프라이버시 중심 AI 워크스페이스.

## 모델 허브 & 오픈 웨이트 모델

- **[Hugging Face](https://huggingface.co)** — 오픈 웨이트 모델·데이터셋 최대 허브이자 로컬 LLM 다운로드의 출발점.
- **[Ollama Library](https://ollama.com/library)** — Ollama로 바로 내려받는 오픈 모델 카탈로그.
- **[Llama (Meta)](https://huggingface.co/meta-llama)** — Meta의 Llama 모델 패밀리.
- **[Qwen (Alibaba)](https://huggingface.co/Qwen)** — 알리바바 클라우드의 Qwen 오픈 웨이트 패밀리.
- **[DeepSeek](https://huggingface.co/deepseek-ai)** — V·R 시리즈를 포함한 DeepSeek 오픈 웨이트 모델.
- **[Mistral AI](https://huggingface.co/mistralai)** — Mistral의 오픈 웨이트 모델.
- **[gpt-oss (OpenAI)](https://huggingface.co/openai/gpt-oss-120b)** — OpenAI의 오픈 웨이트 추론 모델 gpt-oss-120b.
